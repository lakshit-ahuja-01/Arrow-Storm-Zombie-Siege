# Arrow Storm: Undead Siege 🏹🧟‍♂️

> **Unleash devastating archery combos and active ragdoll physics to survive the ultimate undead siege!**

**Arrow Storm: Undead Siege** is an action-packed, physics-driven ragdoll archery defense game built with Phaser 3, Matter.js, and TypeScript. Perched atop your fortified tower, command authentic recurve bow mechanics with dynamic draw tension to fend off relentless waves of mutating undead, siege crawlers, and colossal world bosses.

---

## 🌟 Key Features

* **Active Ragdoll Physics & Visceral Dismemberment**: Every shot carries kinetic momentum—pin enemies to terrain, sever limbs, and trigger lethal physics reactions with dynamic hit reactions.
* **Authentic Recurve Bow Mechanics**: Olympic-style archer posture, dynamic draw flex, high-anchor drawing elbow, and laser/sight stabilization.
* **Diverse Elemental Arsenal**: Fire, Frostbite, Ricochet, Piercing Ballistas, Lightning Arcs, Toxic Viper, Cluster Bombs, and Black Hole vortexes.
* **Tower Defense & Barricade Fortifications**: Fortify barricades, deploy ground caltrops, ignite pitch pits, and weather Blood Moon sieges.
* **Rogue-Lite Progression & Skill Tree**: Unlock dual-weapon builds, stamina overcharges, tactical combat abilities, and legendary hero skins (*Valkyrie*, *Cyberpunk*, *Shadow Assassin*, and *Skeleton*).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Running Locally

```bash
# Clone the repository
git clone https://github.com/lakshit-ahuja-01/Arrow-Storm-Undead-Siege.git

# Enter project directory
cd Arrow-Storm-Undead-Siege

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open `http://localhost:3000` in your browser to play!

### Production Build

```bash
npm run build
```
